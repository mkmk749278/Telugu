# Picture plan v3: real pictures for every sentence (owner, 11 Nov 2026)

Owner: "Don't use that stick man animations. As much as possible use realistic clips and images for every word we are
saying in narration should match scene and situation to that sentence."

So the ink figures (InkRoom, InkWindow, InkCorridor, InkBed, InkDoor, InkHall, InkMirror) are gone. Every sentence now
sits on a real picture, in this order of preference:
1. **Archive footage of the event itself** (news archives on YouTube, short credited excerpts, sound muted): code `F:`.
2. **Real photos** (Commons, GODL-India / PD / CC BY / CC BY-SA): code `P:`.
3. **Real stock footage of the object or place the sentence names** (Pixabay licence, real camera footage only, never
   an AI clip, never an actor who could pass for a real person), labelled **ILLUSTRATIVE FOOTAGE**: code `S:`.

Book excerpts stay as paper cards, but always laid over one of the three above, never over a bare desk.
